# Changelog

## 0.1.0 (research preview)
- Open MLP crash classifier (21 features, 88 KB JSON), trained on 23 simulated scenario types over real UCI HAR sensor texture
- Scenario-held-out evaluation: 93.4% crash recall at 1.0% false alarms; 0 trigger events in 7.3 h of real activity
- Python package (`crashguard`), JS port, Kotlin core, language-neutral spec, parity vectors
- Example Android + Wear OS app and escalation backend (examples/)
